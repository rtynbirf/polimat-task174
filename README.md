**Инвариант:** «проверяй строкой, не смыслом». Вердикты однословные: **[В]** проверено / **[О]** частично, с дырами / **[Н]** непроверяемо (+ **[ОПРОВЕРГНУТО]** для опровергнутого).

## Что это

Эпистемологический протокол и его полевое исполнение. Программа строит цепь носителей
(AВТОРИТЕТ → УВЕРЕННОСТЬ → ВЫВОД) и проверяет её же инструментами: пломба sha256 на каждом
артефакте, ловушки с зарегистрированными ключами до прогона, приёмка независимым чужаком
по одному документу (Б25.8), ведение реестра дыр. Замороженные тексты не ревизуются —
изменения только дельтами с санкции Хозяина; silent mutation = ПРОВАЛ носителя (Блок 14).

|---|---|---|

| Корпус Б25 | пре-регистрация, ловушки T1/T2, вердикты, SEALS_REGISTRY, экспонат N+1 | `corpus/CORPUS_B25/` (снапшот, zip `41b1c849…b969e`) |

## Метод

1. **Пломба до слова** — каждый артефакт несёт sha256; реестр пломб — вне среды носителя.
2. **Пре-регистрация до прогона** — ловушки, ожидания E1–E6, фальсификаторы, критерий вердикта фиксируются ДО запуска чужаков.
3. **Два независимых чужака** — промпты байт-идентичны, контекст автора не выдаётся; акты нормализуются по множеству «узел × вердикт», не по стилю.
4. **Ловушка-индикатор** — незачитанный «ключ внутри» документа = проваленный акт класса «приёмка без эталона».
5. **Реестр дыр** — каждая дыра нумеруется и получает класс; лечение только дельтой, применение только по санкции Хозяина.
