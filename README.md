# ПОЛИМАТ · TASK174 — протокол проверки канона по строкам

**Инвариант:** «проверяй строкой, не смыслом». Вердикты однословные: **[В]** проверено / **[О]** частично, с дырами / **[Н]** непроверяемо (+ **[ОПРОВЕРГНУТО]** для опровергнутого).
**Объект:** канон POLIMAT (документ-прибор) и два тезиса о нём: **В5 «ключ внутри»** (документ проверяем по одному себе) и **В2 «протокол работает»**.
**Статус:** канон **v5.1.2 стабилизирован [В]** (`9384b44a…80dc7`, FROZEN, аудит-след полный); «ключ внутри» **[О]**; «протокол работает» **[Н]** — прогонов меньше порогов.

---

## Что это

Эпистемологический протокол и его полевое исполнение. Программа строит цепь носителей
(AВТОРИТЕТ → УВЕРЕННОСТЬ → ВЫВОД) и проверяет её же инструментами: пломба sha256 на каждом
артефакте, ловушки с зарегистрированными ключами до прогона, приёмка независимым чужаком
по одному документу (Б25.8), ведение реестра дыр. Замороженные тексты не ревизуются —
изменения только дельтами с санкции Хозяина; silent mutation = ПРОВАЛ носителя (Блок 14).

|---|---|---|

## Метод

1. **Пломба до слова** — каждый артефакт несёт sha256; реестр пломб — вне среды носителя.
2. **Пре-регистрация до прогона** — ловушки, ожидания E1–E6, фальсификаторы, критерий вердикта фиксируются ДО запуска чужаков.
3. **Два независимых чужака** — промпты байт-идентичны, контекст автора не выдаётся; акты нормализуются по множеству «узел × вердикт», не по стилю.
4. **Ловушка-индикатор** — незачитанный «ключ внутри» документа = проваленный акт класса «приёмка без эталона».
5. **Реестр дыр** — каждая дыра нумеруется и получает класс; лечение только дельтой, применение только по санкции Хозяина.

## Воспроизводимость

```bash
python3 scripts/build_v512.py           # сборка v5.1.2 из v5.1.1 + дельты (15 правок, assert)
python3 scripts/verify_b25_final.py     # пересверка 9 файлов корпуса с SEALS_REGISTRY
python3 scripts/prep_blind_svazka.py    # слепая рука прогона 3 + пересверка 12/12 пломб
```

Все пломбы сверяются в одну команду: `sha256sum -c MANIFEST_SHA256.txt`.
Критические: канон `9384b44a…80dc7`, связка `409d934e…c05d6fa`, вердикт прогона 3 `44076a09…11ac70`, К3 v1 `1cfe7f39…31645d`.

## Границы

- Опубликованные акты чужаков перенесены вербатим (`run3_svazka/Б25_ПРОГОН3_АКТ_SA/SB.md`) — не ретушировались, включая расхождение routing-вердикта по ярлыку №12.
- Прогон 3 не закрывает: К3-батарею (F№4), К1-arm, Б25.4; счётчик L5 не тронут.
- Замороженные тексты (v5.1.1, v5.1.2, вердикты прогонов 1–2, связка v1.0) не ревизованы ни в одном коммите этого репо — проверяется `MANIFEST_SHA256.txt`.
